# تنفيذ نظام العرض — 26 سبتمبر 2026

## المنفذ محليًا

- SiteHeader واحد يضم الاسم والتنقل واللغة والدخول والرجوع، وقائمة مخصصة للشاشات حتى 1100px. في الجوال حتى 600px يصبح الاسم في صف مستقل، دون تداخل الأزرار.
- إزالة رؤوس الرجوع المكررة، مع إبقاء «تغيير المسار» داخل عالم الهوية كإجراء مستقل.
- ألوان دلالية مستقلة للنص الثانوي والحدود والأسطح والإجراء الذهبي. ألوان أدلة العلامات مستقلة.
- أنماط ui-button وui-icon-button وui-card مشتركة، وأهداف لمس 44–48px وتركيز مرئي.
- تطبيق الأزرار على الرئيسية والخبرات والأنماط القديمة المشتركة؛ بطاقات الأعمال أزرار أصلية تدعم Enter وSpace وشبكتها تستوعب 320px.
- الخطوط الحالية العربية والإنجليزية محفوظة، وتوحيد وراثة خط الحقول والأزرار.
- احترام تفضيل تقليل الحركة في MotionConfig وCSS. هذا لا يعني اكتمال مراجعة جميع مؤثرات JavaScript القديمة.
- إصلاح استيرادات Expertise وSciFiHub المفقودة التي كانت تعطل مسار الخبرات.
- خصم مساحة الرأس من إطار دليل العلامة، دون إعادة تصميم محتوى الدليل.

## التحقق

نجح npm run build. بقي تحذير كبر حزمة JavaScript السابق.

فحص Chrome محليًا: الرئيسية بعروض 320 و390 و768 و1366 وارتفاع 844، بالعربية والإنجليزية. قياسات الرأس والشبكة داخل العرض، ومراجعة لقطات الجوال والتابلت واللابتوب. أزرار الرئيسية تتراص في الجوال، وتتجاور عندما تتسع المساحة.

فحص DOM للرأس والعناوين في /expertise و/brand-gallery و/creative-direction و/legacy و/brand-identity و/login على 390 و768 و1366 باللغتين: الرأس داخل العرض والصفحات تظهر. هذا فحص للرأس، وليس اعتمادًا لكل محتويات هذه الصفحات.

اختبار فتح قائمة الجوال وإغلاقها بـEscape، تبديل اللغة، وفتح بطاقة سوميفاي بـEnter نجح. ظهر المحتوى التفصيلي للفيديو. فحص lint للمكون الجديد مستقل؛ الأخطاء القديمة في باقي الملفات ليست ضمن هذا الإصلاح.
